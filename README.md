# Catálogo de música — instaladores

Para bajar el programa, entrá a **[Releases](../../releases/latest)** y elegí el de tu computadora:

- **Windows:** el archivo que termina en `.exe`
- **Mac:** el que termina en `.dmg`
- **Linux (Ubuntu):** el que termina en `.deb`

El programa avisa solo cuando hay una versión nueva y la baja desde acá.
